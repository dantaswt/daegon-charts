Get in touch

Contact

Daegon Charts welcomes corrections, source suggestions, technical reports and questions about the archive. Because historical chart work is continuously reviewed, specific reports about duplicated entries, incorrect artist credits, broken chart runs or missing artwork are especially useful.

Project contact

The current public contact channel is the project's GitHub repository. You can open an issue with enough detail to reproduce the problem.

Open an issue on GitHub

What to include

  • The chart name and chart week.
  • The song, album or artist involved.
  • What appears to be incorrect.
  • A source or reference when reporting historical data.
  • Device and browser details for technical problems.

Privacy requests

Privacy-related questions can use the same contact channel. Do not post sensitive personal information in a public issue.
